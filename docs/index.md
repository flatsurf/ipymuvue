# ipyμvue

Reactive [Vue 3](https://vuejs.org) widgets for the Jupyter notebook in Python.

```
pip install ipymuvue
```

The examples below were executed when this documentation was built. Their
widgets work on these static pages as long as they do not need to call back
into Python. To try everything, run the examples in JupyterLab, see the
[README](https://github.com/flatsurf/ipymuvue#readme).
